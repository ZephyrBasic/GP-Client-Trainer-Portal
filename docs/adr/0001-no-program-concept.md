# No Program concept; the app holds workouts, not programming

A trainer's programming — periodisation, nutrition, the shape of a training block — is authored
and delivered to clients outside this app, and duplicating that structure here would mean
maintaining the plan twice. So there is no Program object: a program update reaches the app only
as new or updated Workout Templates, and a client sees a flat list of assigned workouts they can
start on any day, in any order, any number of times.

## Consequences

There is no schedule, so there is no notion of a *missed* workout and no date a workout is due.
Reporting that a Client is behind therefore rests on a Target Frequency recorded on each
Assignment ("Upper Body A, 1x per week") rather than on anything derived from a calendar.
